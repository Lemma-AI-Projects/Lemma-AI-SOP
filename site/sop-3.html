战略分析 SOP

重新理解现实 → 审视判断 → 比较路径 → 决策 → 更新

战略分析用于处理会显著改变公司方向、资源配置或长期计划的事情。

1. 什么时候启动

出现以下情况之一时，启动战略分析：

  • 市场或竞争环境发生重大变化
  • 技术路线发生重大变化
  • 产品方向需要重大调整
  • 商业模式发生变化
  • 法律、组织或公司结构发生重大变化
  • 发现原有重要判断可能错误
  • 出现可能改变公司未来的重要机会

日常问题不进入战略分析。

2. 重新看现实

不要直接讨论“怎么办”。

先确认：

发生了什么？什么真的变了？

把事实、判断、假设分开。

重点找到：

哪个变化可能真正影响我们的方向？

3. 审视原来的判断

问：

我们为什么走现在这条路？
当初依赖什么判断？
这些判断现在还成立吗？

如果原来的核心假设已经失效，就不能因为“已经投入很多”而继续沿用。

4. 比较路径

不要只讨论自己最喜欢的方案。

至少明确：

继续 / 调整 / 转向

比较它们的：

收益、代价、风险、关键未知

如果最大的未知无法判断：

先验证，而不是强行决策。

5. 决策

形成明确结论：

现在选择哪条路径，以及为什么。

决策不是讨论的结束，而是公司行动的开始。

6. 更新现实

战略决策确定后，同步改变受影响的：

  • 目标
  • 计划
  • 产品
  • 技术路线
  • 资源分配

正式的战略判断、计划与公司信息 → 正式文档区

个人后续计划 → 自我曝光文档

具体执行任务 → 飞书多维表格

如果过程中出现新的机会、风险或未成熟想法：

→ 提案区

7. 重新验证

战略没有永久有效期。

当现实再次发生重要变化，或者关键判断出现新的证据：

重新启动战略分析。

核心原则

战略不是预测未来，而是在现实变化时，持续判断我们应该把力量放在哪里。

不要因为过去的选择正确，就假设它对未来仍然正确。
